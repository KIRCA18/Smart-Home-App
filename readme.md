## 1. Опис
**Smart Home Application** е веб-базиран систем кој му овозможува на корисникот:  
- да креира акаунт,  
- да додава куќи (или други објекти),  
- да дефинира простории во рамки на куќата,  
- да додава и контролира паметни уреди во тие простории,  
- да ги надгледува уредите преку Dashboard.  

Во поновата верзија на апликацијата се воведени нови функционалности:  
- **Групирање на уредите**: корисниците можат да креираат групи и да управуваат со повеќе уреди истовремено.  
- **Автоматизации**: покрај директна контрола, системот овозможува креирање на различни типови автоматизации:  
  - **Временски автоматизации** (извршување на акции во одредено време),  
  - **Вредносни автоматизации** (акции кои се активираат кога некоја мерена вредност ја достигнува зададената вредност),  
  - **Сигнални автоматизации** (реакција на одреден настан или сигнал),  
  - **Автоматизации според временска прогноза** (користејќи надворешен API за метеоролошки податоци).  

Автоматизациите поддржуваат поврзување на повеќе услови со логички операции **AND** и **OR**, што овозможува дефинирање на комплексни сценарија.  

Дополнително, системот овозможува **додавање членови во куќата**. Секој член има пристап до управување со уредите, но само **еден корисник е администратор**, кој има право да додава и отстранува членови.

## 2. Технологии што ги користев
- **Backend:** Django (Python) – за серверска логика и управување со податоците.  
- **Frontend:** HTML, CSS, JavaScript – за кориснички интерфејс.  
- **MQTT (Mosquitto):** за комуникација со IoT уредите.  
- **ESP8266/ESP32:** како микроконтролери за управување со уредите.  
- **PostgreSQL:** релациона база на податоци за чување информации за корисници, уреди и автоматизации (надградено од претходната SQLite база).  
- **Celery:** систем за асинхроно извршување на задачи (task scheduling), користен за временските автоматизации.  
  - За работа со Celery потребно е да се инсталираат **Erlang** и **RabbitMQ Server**.

## 3. Requirements (Барања)
### За Windows:
1. **Python (верзија 3.11 или понова)**  
   Преземете и инсталирајте од [официјалниот сајт](https://www.python.org/downloads/windows/).  
   Изберете ја опцијата „Add Python to PATH“.  

2. **Django и останати библиотеки**  
   Инсталација преку `requirements.txt`.  

3. **PostgreSQL**  
   Преземете и инсталирајте од [официјалниот сајт](https://www.postgresql.org/download/).  

4. **MQTT брокер (Mosquitto)**  
   Инсталација од [Mosquitto сајтот](https://mosquitto.org/download/).  

5. **Erlang и RabbitMQ Server**  
   - Erlang: [Erlang Downloads](https://www.erlang.org/downloads)  
   - RabbitMQ: [RabbitMQ Downloads](https://www.rabbitmq.com/download.html)  

### За Linux:
1. **Python (верзија 3.11 или понова)**
   - Инсталирајте го Python преку терминалот:
     ```bash
     sudo apt-get install python3
     ```

2. **Django библиотека (верзија 3.0 или понова)**
   - Инсталирајте ја Django библиотеката со pip:
     ```bash
     pip install django
     ```

3. **MQTT брокер (Mosquitto)**
   - Инсталирајте го Mosquitto брокерот:
     ```bash
     sudo apt-get install mosquitto
     sudo apt-get install mosquitto-clients
     ```
4. **PostgreSQL**
    ```bash
    sudo apt-get install postgresql postgresql-contrib
    ```
5. **Erlang и RabbitMQ Server**
    ```bash
    sudo apt-get install erlang
    sudo apt-get install rabbitmq-server
    ```

## 4. Како да го стартувате проектот
### 1. Клонирање на проектот
```bash
git clone https://github.com/KIRCA18/Smart-Home-App.git
cd Smart-Home-App
```

### 2. Креирање и активирање на виртуелна околина:
```bash
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows
```

### 3. Инсталирање на библиотки
```bash
pip install -r requirements.txt
```

### 4. Конфигурација на .env датотеката
- Во директориумот на проектот креирајте .env датотека и внесете ги следниве вредности:
    ```
    WEATHER_API_KEY=вашиот_API_клуч
    DB_NAME=име_на_база
    DB_USER=корисничко_име
    DB_PASSWORD=лозинка
    DB_HOST=localhost
    DB_PORT=5432
    ```

### 5. Стартување на MQTT брокерот (Mosquitto)
```bash
mosquitto -c /path/to/mosquitto.conf
```

### 6. Миграции и стартување на серверот
```bash
python manage.py migrate
python manage.py runserver
```

### 7. Стартување на Celery процеси (потребни за временските автоматизации)
- Во различни терминали (со активна .venv околина и во smarthomeapp директориумот):
    ```bash
    python -m celery -A smarthomeapp beat --loglevel=info
    ```
    ```bash
    python -m celery -A smarthomeapp worker --loglevel=info -P solo
    ```

## 5. Предизвици и проблеми со кои се соочив
- **Интеграција на IoT уреди:** Најголемиот предизвик беше интеграцијата на ESP8266 микроконтролерите со MQTT и Django серверот. Се појавија проблеми со автентикација и CSRF грешки при испраќање POST барања од уредите кон серверот.
- **Синхронизација на податоците:** Предизвик беше и како да се осигура дека податоците од уредите се ажурираат во реално време на корисничкиот интерфејс.
- **Автоматизации:** Дизајнирањето на услови со повеќе логички оператори (AND/OR) претставуваше предизвик, но истовремено ја зголеми флексибилноста на системот.
